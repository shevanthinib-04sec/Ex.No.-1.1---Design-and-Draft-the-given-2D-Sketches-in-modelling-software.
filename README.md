# Ex.No.-1.1-Design and Draft the given 2D Sketches in modelling software.

## AIM

To sketch the given drawing with dimensions using fusion 360 tool.

## REQUIREMENTS

  1. Autodesk fusion 360
  2. Windows 10
  3. 16 GB of RAM (integrated graphics recommend 2 GB or more)
  4. 2.5 Mbps or faster download; 500 Kbps or faster upload 
  
## PROCEDURE

1. Open Fusion 360 and start a new sketch. Select the XY plane to work flat.
2. Fist draw the main circles. Create the big outer circle (Ø66), then the central one (Ø40). Add the smaller ones: Ø32 at the top at the distance Ø65 from the origin, Ø20 for the top hole, a Ø20 circle for the bottom center hole at the distance Ø50 from the origin, and Ø10 for the bottom right hole.
3. Next, create a circle with Ø128 and apply tangent constraints so that it touches both the top circle (Ø32) and the central circle (Ø66). 


![image](https://user-images.githubusercontent.com/113594316/198206497-ca83d495-119b-45cd-b43d-8ca3ea7e9544.png)

4. Create two circles in the 3rd quadrant with radii 20 and tangent constraint them with the bottom circle(Ø20) and right circle (Ø20).

6. Trim away extra lines.


![image](https://user-images.githubusercontent.com/113594316/198206562-68463016-3f32-4a87-aa5b-7a17dd023b31.png)

6. Mirror the sketch vertically 

7. Click **Finish Sketch** to lock it in, press pull the whole sketch

 8. Switch over to drawing mode. Go to **Design → Drawing → From Design**. In the dialogue box repeat the sketch in different angle views.

![image](https://user-images.githubusercontent.com/113594316/198206639-31c4bdb5-b13e-4106-bcf5-125c294aa03e.png)

 9. Finally, add the dimensions to the drawing. Label the circles and arcs with Ø and R values, and mark the distances clearly.

![image](https://user-images.githubusercontent.com/113594316/198206697-2e3ead2b-7d1e-436e-bc36-aa2e73c1e78e.png)

10. Save your work, and export the drawing.
